## 1. أسس التوجيه الأربعة

1. **الشعبة والنتائج** — شعبة البكالوريا والمعدل (الموزون أو العام)
2. **الرغبات المعبّر عنها** — القائمة التي يختارها الطالب
3. **الطاقة الاستيعابية** — عدد المقاعد المتاحة في كل مؤسسة
4. **الدوائر الجغرافية** — تجميع الولايات في مناطق جغرافية

---

## 2. المعدل الموزون المحسوب (الصيغة الرسمية)

```
المعدل الموزون = (معدل البكالوريا × 2 + علامة المادة الأساسية) ÷ 3
```

**المادة الأساسية حسب الميدان:**
- رياضيات وإعلام آلي (MI): علامة الرياضيات
- علوم وتكنولوجيا (ST): علامة الفيزياء
- علوم المادة (SM): علامة الفيزياء
- طب وصيدلة وطب أسنان: علامة علوم الطبيعة والحياة
- حقوق وعلوم سياسية: علامة اللغة العربية
- اقتصاد وتسيير وتجارة: علامة التسيير أو الاقتصاد
- لغات أجنبية: علامة اللغة الأجنبية المختارة

## 5. المدارس العليا للأساتذة (ENS) — شروط مشتركة

> ⚠️ **تنبيه**: الحد الأدنى لكل مسارات ENS هو **معدل البكالوريا ≥ 14/20**
> (خطأ شائع في قواعد البيانات التي تضع 10/20 أو 12/20)

### شروط إضافية لكل مسار:

| المسار | الشرط الإضافي |
|--------|--------------|
| رياضيات (أستاذ ثانوي) | (رياضيات + فيزياء) ÷ 2 ≥ 13.5/20 |
| فيزياء | (رياضيات + فيزياء) ÷ 2 ≥ 13.5/20 |
| علوم طبيعية | (رياضيات + علوم الطبيعة) ÷ 2 ≥ 13.5/20 |
| لغة عربية | علامة اللغة العربية ≥ 13/20 |
| لغة فرنسية | علامة اللغة الفرنسية ≥ 13/20 |
| لغة إنجليزية | علامة اللغة الإنجليزية ≥ 13/20 |
| فلسفة | علامة الفلسفة ≥ 13/20 |
| إعلام آلي | علامة الرياضيات ≥ 13/20 |
| علوم إسلامية | علامة الدراسات الإسلامية ≥ 13.5/20 |
| موسيقى | شعبة فنون: قبول بدون مسابقة / كل الشعب الأخرى: مسابقة |
| إيطالية / ألمانية / إسبانية | علامة اللغة ≥ 13.5/20 + معدل ≥ 14/20 | FRN |

## 7. مدارس أخرى (وزارات أخرى) — شروط خاصة

| المؤسسة | الشرط الخاص |
|---------|------------|
| **المدرسة الوطنية العليا للسياحة** | مسابقة (كتابي + شفوي) — الحد الأدنى للبكالوريا 10/20 للمشاركة في المسابقة |
| **هندسة معمارية** | اختبار الكفاءات الفنية (رسم + كتابي) إلزامي قبل الترتيب |
| **المعهد الوطني العالي للسينما** | شعبة فنون: قبول مباشر — كل الشعب الأخرى: مسابقة |
| **المعهد الوطني العالي للموسيقى** | شعبة فنون: قبول مباشر — كل الشعب الأخرى: مسابقة |
| **INPTIC (تكنولوجيا الاتصالات)** | الصيغة: (BAC×2 + (فيزياء + رياضيات)/2) ÷ 3 |

## 11. أخطاء شائعة في قواعد البيانات — تصحيحات رسمية

| الخطأ الشائع | الصحيح من الدليل الرسمي |
|-------------|------------------------|
| الطب يقبل معدل 10/20 أو 12/20 | ❌ الصحيح: **معدل ≥ 14/20** شرط الأهلية |
| ENS يقبل معدل 10/20 أو 12/20 | ❌ الصحيح: **معدل ≥ 14/20** لكل مسارات ENS |
| علوم البيطرة تقبل بنفس شروط علوم الطبيعة (12/20) | ❌ الصحيح: **معدل ≥ 14/20** + شروط مشددة |
| STAPS تطلب شعبة علوم | ❌ الصحيح: **كل الشعب أولوية 1** — الشرط اختبار اللياقة البدنية فقط |
| الطب شبه الطبي له حد أدنى للمعدل | ❌ الصحيح: **لا حد أدنى** — ترتيب بالمعدل ضمن مقاعد الولاية |
| مدرسة السياحة قبول بالمعدل فقط | ❌ الصحيح: **مسابقة كتابية + شفهية** |
| الهندسة المعمارية قبول بالمعدل فقط | ❌ الصحيح: **اختبار الكفاءات الفنية إلزامي** |
| تقني رياضي مقبول في الطب | ❌ الصحيح: **غير مقبول (NC)** في طب وصيدلة وطب أسنان |
| الجزائر 48 ولاية | ❌ الصحيح: **58 ولاية** منذ 2019 |
