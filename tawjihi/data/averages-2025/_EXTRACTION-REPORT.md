## 1. What the document actually is (IMPORTANT — schema deviation)

The task brief assumed an Arabic RTL table with one minimum per (program × BAC stream)
and labels like علوم تجريبية / رياضيات. **The actual PDF is different:**

- It is **entirely in French** (Latin script). There are **no Arabic names anywhere**
  in the document, so `name_ar` / `institution_ar` are `null` in every entry.
  Arabic names must be joined from the Tawjihi catalog / Guide BAC 2025.
- It is **one continuous ruled table** over 274 pages with columns:
  `Code Etb | Etablissement | Code Fil | Filiere | Min1 | Min2 | Min3`.
- **Min1/Min2/Min3 are NOT per-stream minima.** They are the minimum admission
  averages per **eligibility priority group** (الأولوية أ1/أ2/أ3) as defined per
  filière in the Guide BAC 2025 stream→field eligibility matrix. The document's own
  footnote confirms this: *"Pour les moyennes minimales avec la mention '--', aucun
  bachelier n'a été affecté dans **la priorité considérée**."*
- Which BAC streams sit in priority 1/2/3 varies **per filière** and is defined in
  the Guide BAC 2025 (`tawjihi/data/guide-bac2025-extracted.md`), not in this PDF.
  Attributing a stream to each column here would have been guesswork, so it was not
  done. **To get per-stream minima, join `code`'s filière with the guide's
  eligibility/priority matrix.**
- The PDF also never distinguishes معدل عام vs معدل موزون per row, so the requested
  `basis` field is omitted (per the guide, ranking uses the weighted average where
  the filière defines weighting).

## 2. Method

1. **Probe:** `pypdf` page count (274) + text sample → document is born-digital text
   (not scanned), French, single ruled table per page.
2. **Primary extraction:** Python `pdfplumber` `extract_tables()` (lines strategy on
   the ruled grid) on every page. Multi-line wrapped cells re-joined with single
   spaces. Exactly 1 table and 1 header row per page on all 274 pages.
3. **Strict cell validation:** every Min cell had to match `^\d{1,2}\.\d{2}$`, `NC`,
   `--`, or blank. **Any other content would be flagged UNREADABLE, never guessed —
   zero such cells occurred.**
4. **Cross-check (independent method):** raw text extraction (`extract_text`) per
   page, counting filière-code tokens (`[A-Z][A-Z0-9]\d[A-Z]{2}[A-Z]\d{2}` or
   `[A-Z]\d{2}SANTE`) in the table body. **Matched the table row count on 274/274
   pages.** (Visual page rendering via `pypdfium2` was used for the spot-check below;
   the Read tool's native PDF rendering was unavailable — no pdftoppm.)
5. **Visual spot-check:** 10 random entries (seed 2025) re-verified against
   full-page PNG renders (see §5).

## 6. Known limitations / notes for downstream use

- Floats: JSON stores numbers, so trailing zeros are not preserved textually
  (`10.00` → `10.0`, `14.00` → `14.0`). Values are numerically identical to the PDF;
  format with 2 decimals when displaying.
- ENS and paramedical rows repeat the same filière code once per recruiting wilaya;
  the wilaya is embedded in `name_fr` («-- pour bacheliers X»). The `--` inside those
  names is the PDF's own separator, not a missing value.
- These are **phase-1** minima; the PDF itself states NC minima will only be fixed
  after phase 2. Treat all values as provisional-official for 2026 estimation.
- To convert to per-stream minima for the Tawjihi UI, join `code` (first 3 chars =
  domain/filière) with the Guide BAC 2025 priority matrix
  (`tawjihi/data/guide-bac2025-extracted.md`), then map priority أ1/أ2/أ3 → streams
  per filière.
