# BAC STORY 🎓

**The ultimate, high-performance platform for Baccalaureate preparation in Algeria.**

![BAC STORY Logo](favicon.png)

## 🌟 Overview

**Bac Story** is a state-of-the-art educational platform designed to empower Algerian Baccalaureate students. It combines a vast library of academic resources with a premium, high-speed user interface, ensuring that study time is both effective and visually engaging.

## 🚀 Key Features

* **Smart Search Engine**: A powerful, localized search system supporting over 200+ detailed keywords. It features intelligent Arabic normalization (handling "Al-", Hamzas, and Taa Marbutas) for instant access to results.
* **Comprehensive Academic Records**: Dedicated sections for all major subjects (Math, Physics, Sciences, Languages) featuring curated summaries, exercises, and past papers.
* **University Guide 2025**: A full directory of university majors and admission rates to help students plan their higher education journey.
* **Specialized Study Tools**: Integrated utilities including a focal Study Timer, Baccalaureate GPA Calculator, and study packages.
* **Synchronized Responsiveness**: A seamless layout transition at **1100px**, ensuring the desktop and mobile experiences are high-quality across any device.
* **Premium UX/UX Aesthetics**:
  * **Dynamic Zoom Loader**: A striking white-themed loader with a high-impact logo zoom and blur animation.
  * **Zero-Flash Transitions**: Optimized page transitions that eliminate the "white flash" effect between navigation.
  * **Glassmorphism Design**: Modern, transparent UI elements for a sleek and professional feel.

## 🛠️ Technology Stack

* **Core**: HTML5, Vanilla CSS3 (Custom Design System), Modern JavaScript (ES6+).
* **Modular Architecture**: Dynamic component injection (Navbar, Search, Footer) via `shared.js`.
* **Vercel Optimized**: Configured with `vercel.json` for high-performance caching and Clean URLs.
* **Icons & Typography**: Font Awesome 6 and Google Fonts (Tajawal, Pattaya).

## 📂 Project Structure

```text
├── components/          # Reusable UI components (Navbar, Search, Loader)
├── images/              # Visual assets and branding
├── index.html           # Optimized landing page
├── style.css            # Central Design System and animations
├── script.js            # General application logic
├── components/shared.js # Search engine and component injection logic
└── vercel.json          # Production deployment configuration
```

## 🌐 Deployment

This project is production-ready for **Vercel**. Use the provided `vercel.json` to enable professional routing (e.g., `bacstory.com/university` instead of `university.html`).
